# Jen working-tree quarantine

`templates/` contains the compact FSFs selectively recovered from the later
`DVS-Lab/srndna-ug` working repository. They preserve potentially relevant
analysis history, but none is authoritative merely because it is newer than
the original repository.

The source repository and any server backup should be retained read-only
outside this repository. For any additional import, first record the original
repository/path, commit or filesystem timestamp, byte count, and SHA-256 in a
manifest. Import only a compact file needed to understand the paper, and give
it a canonical replacement or disposition. Do not import generated FEAT
directories, BIDS data, RL/DDM tutorials or fits, caches, screenshots, or
general lab utilities.

Files promoted into the active revision must be copied deliberately into
their canonical location and validated against rendered production designs.
The quarantined source remains unchanged for provenance.
